## Regras para liberar uma pagina futura

- Ter pelo menos 8 produtos reais na categoria.
- Ter preco real capturado quando a pagina depender de custo-beneficio ou faixa de preco.
- Ter composicao confirmada quando a pagina depender de concentracao, pureza ou dose.
- Ter ranking validado quando a pagina usar "melhor nota".
- Ter fonte de venda ou criterio objetivo quando a pagina usar "mais vendido".
- Evitar paginas de superlativo quando os dados forem insuficientes para diferenciar produtos.
